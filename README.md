# DevOps Assessment

This repository contains a basic implementation of the DevOps assessment.

## Technologies

- Terraform
- AWS
- Docker Compose
- PostgreSQL
- GitHub Actions
- Shell scripting

## Structure

- infra/ - Terraform infrastructure
- database/ - Local PostgreSQL setup
- scripts/ - Backup and restore scripts
- .github/ - GitHub Actions workflow

## Database

The database can be started using Docker Compose.

## Terraform

Terraform files are provided for basic AWS infrastructure and separate dev and prod environments.

## Backup

A basic PostgreSQL backup script is included.

## Restore

A basic restore script is included.
